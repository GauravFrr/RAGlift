# Supported Webhook Event Types Catalog

Subscribe to specific event categories:

- Billing Events: `invoice.paid`, `invoice.payment_failed`, `subscription.created`, `subscription.canceled`
- Access Events: `user.created`, `user.deleted`, `api_key.created`
- Deployment Events: `deployment.started`, `deployment.succeeded`, `deployment.failed`
- Database Events: `db.backup_completed`, `db.storage_warning`
