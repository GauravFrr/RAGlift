# Metered Usage-Based Billing Metrics

In addition to base subscription fees, metered resources are billed based on actual monthly consumption:

- Active Compute Hours: $0.05 per vCPU hour.
- Outbound Network Egress: $0.08 per GB transferred outside regional cloud zones.
- Vector Index Storage: $0.25 per GB per month.

Usage meters update hourly in the Billing Metrics dashboard.
