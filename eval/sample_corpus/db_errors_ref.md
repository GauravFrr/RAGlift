# Database Error Codes Reference

Common database operational errors and system codes:

- `ERR_DB_DEADLOCK_DETECTED`: Concurrent transactions attempted conflicting lock acquisition.
- `ERR_DB_POOL_EXHAUSTED`: Available PgBouncer client pool slots are fully consumed.
- `ERR_DB_STORAGE_FULL`: Database volume disk space is exhausted and auto-scaling failed.
- `ERR_DB_REPLICATION_LAG`: Read replica exceeds maximum allowed replication delay threshold.
