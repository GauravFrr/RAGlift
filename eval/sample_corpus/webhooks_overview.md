# Webhook Event Subscriptions & Architecture

Webhooks deliver real-time notifications to your HTTP application endpoint when events occur within your CloudScale account.

Key Features:
- At-least-once event delivery guarantee.
- JSON-formatted event payloads containing event ID, timestamp, event type, and data payload.
- Asynchronous out-of-band HTTP POST delivery.

Configure webhook endpoints in the developer dashboard under Webhooks -> Add Endpoint.
