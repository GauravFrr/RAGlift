# Installing the CloudScale Command-Line Interface (CLI)

Install the official `cloudscale` CLI utility across supported operating systems:

- macOS (Homebrew): `brew install cloudscale/tap/cloudscale`
- Node.js (npm): `npm install -g @cloudscale/cli`
- Linux / Windows: Download standalone binary executables from GitHub releases.

Verify installation by running `cloudscale --version`.
